# mojo-xxhash v0.1.0

## What it does
xxHash in pure Mojo: XXH32, XXH64, XXH3-64, XXH3-128, seeded, one-shot and streaming.

## Highlights
- Identical to the reference on 1,592 one-shot lines and 306 streaming cases.
- XXH3-64 at 51.6 GB/s on this machine, 2.3x the packaged C library.

## Changes
- First release.

## Verified
- `scripts/ci.sh` PASS on Mojo 1.2.0 and 1.3.0.dev2026110305: one-shot, streaming and file (xxhsum -H0/1/3/128 digests) scenarios identical with Python xxhash 3; CI needs no xxhsum binary.6.0 / xxhsum 0.8.4, each twice; 7/7 mutants.

## Known limits
- No custom secrets (`XXH3_64bits_withSecret`), no XXH128 streaming copy/reset API, little-endian hosts only.

## Upgrade / run
- Add `mojo-xxhash`, then `from xxhash import xxh3_64`. Try `examples/quickstart.mojo`.
